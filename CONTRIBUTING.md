# Contributing to Damper Frontend

This repository is at the design stage: there is no application code yet. The planned views are in the [README](README.md), and they depend on the read API listed on the [backend roadmap](https://github.com/UbsOrg/damper-backend/blob/main/ROADMAP.md).

If you want to help, open an issue describing what you would build and what data it needs, so we can agree the shape of the backend API first. For shared rules (labels, commit messages, code of conduct) see the [organisation guide](https://github.com/UbsOrg/.github/blob/main/CONTRIBUTING.md). Setup, checks and a test requirement will be added here when the first code lands.

Do not open public issues for vulnerabilities. See [SECURITY.md](https://github.com/UbsOrg/.github/blob/main/SECURITY.md).
